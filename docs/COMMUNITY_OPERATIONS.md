# 管理端社区运营指南

管理员登录后进入「社区运营」。新权限由管理库 Flyway V2 为内置管理员授予；其他角色需要在「系统管理 → 角色管理」中明确勾选。页面和服务端均按操作权限限制访问。

| 管理页面 | 功能 | 权限前缀 |
| --- | --- | --- |
| 社区账号 | 搜索、详情、禁用/恢复；操作需要原因，撤销该用户已有登录 | `community:user:*` |
| 帖子审核 | 搜索、状态筛选、详情、公开/待审/隐藏、置顶/加精、删除 | `community:post:*` |
| 评论管理 | 搜索、详情、隐藏/恢复、删除；根评论状态影响回复展示 | `community:comment:*` |
| 社区公告 | 新增、编辑、展示开关、删除 | `community:billboard:*` |
| 社区提示语 | 新增、编辑、启用开关、删除 | `community:tip:*` |
| 社区推广链接 | 新增、编辑、删除；只允许 HTTP(S) 地址 | `community:promotion:*` |
| 社区标签 | 新增、重命名、删除；被帖子使用的标签不能直接删除 | `community:tag:*` |
| 运营审计 | 按操作者/操作搜索，查看时间、资源和处理原因 | `community:audit:list` |

新帖默认公开；运营可将帖子设为待审或隐藏。作者通过「我的帖子」查看处理原因，编辑非公开帖子后进入待审，由运营重新审核。隐藏内容不会出现在公开详情、搜索、收藏和相关互动中。运营操作保存操作者与原因；审计记录不提供编辑或删除入口。

两后端需配置相同的 `COMMUNITY_ADMIN_KEY`，管理后端使用 `COMMUNITY_API_URL` 连接社区服务。详细服务端契约见 [运营 API](../../liushao_community_backend/docs/OPERATIONS_API.md)，运行方式见 [部署说明](../../liushao_community_backend/deploy/README.md)。
